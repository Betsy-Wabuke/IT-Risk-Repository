# IT Risk Repository

A practical repository documenting IT Risk Management, Risk & Control Self-Assessment (RCSA), IT controls, risk assessment, governance, and technology risk practices.

## 🎯 Purpose

This repository is a practical learning and professional portfolio for understanding and applying IT Risk Management principles.

It will progressively document:

* IT Risk Management concepts
* Risk identification and assessment
* Risk and Control Self-Assessment (RCSA)
* IT controls and control testing
* IT Risk scenarios and case studies
* Risk treatment and remediation
* IT governance and frameworks
* Practical IT Risk tools and templates

## 📌 Key Areas

| Area                     | Focus                                                     |
| ------------------------ | --------------------------------------------------------- |
| IT Risk Management       | Risk identification, assessment, treatment and monitoring |
| RCSA                     | Risk and control identification and assessment            |
| IT Controls              | Control design, effectiveness and testing                 |
| Access Management        | User access, privileged access and account lifecycle      |
| Vulnerability Management | Vulnerabilities, remediation and monitoring               |
| Change Management        | Change authorization, testing and implementation          |
| Security Monitoring      | Security events, alerts and monitoring controls           |
| IT Governance            | Policies, standards, frameworks and oversight             |

## 🛠️ Practical Approach

The repository will focus on moving from theory to practical application:

**Understand → Identify → Assess → Control → Test → Remediate → Monitor**
